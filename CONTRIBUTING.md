### ABOUT AI/LLM

this project will not accept AI code by any source of origin.\
so please, do not send anything that was made by generative AI

using for debugging or testing new things is ok\
but make sure do not send the code as is\
do some review before sending anything

### ABOUT PRs

I don't accept new functions or features directly,
only bug fixes

if you want some new functionality, open an Issue first\
if you already have some code, then open a Draft PR\
just for me to check how the code is

normally I do not check GitHub so often\
so it may take a while for me to see the PRs,\
so please be patient.

When sending a PR
* write the main change
* explain what was the issue
* write the commits by yourself, don't use AI for it

if your english is bad, it's ok, even my english is bad
